# EventHub

A cross-platform event booking mobile app built with React Native (Expo) and Firebase.

## Features
- User accounts (register, login, logout, profile)
- Browse, search, and filter events
- Event details and booking
- My Bookings (view and cancel)
- Organizer tools (create, edit, delete events; view bookings)

## Tech stack
- React Native (Expo)
- Firebase (Firestore, Auth, Cloud Messaging)
- AsyncStorage for local storage

## Getting started
\`\`\`bash
cd mobile
npm install
npx expo start
\`\`\`
